## Essential mathematics and visual semantics

**Breakout Score** from \`calculated_metrics.breakout_score\` equals the exact stored sum \`score_creator_component + score_growth_component + score_engagement_component + score_freshness_component\`. It is a **weighted, unbounded diagnostic score**. It MUST NOT be shown as \`P(viral)\`, \`score/100\`, a probability, percentage or range 0–100. \`freshness_score\` itself has its own separately bounded scale but the overall Breakout Score does not. Components are returned from certified GC20 persistence; no Javascript calculation or independently multiplied coefficients. Chart uses actual \`metric_snapshots.views\` and \`observed_at\`, never discovery/ingest clock, max 48 rows and original source/policy/metric version, only unexpired exact/nonretracted observations; source retention days also bound historical observation times. Client chart coordinates are presentation-only and require safe integers and monotonic timestamps. All authoritative Decimal labels remain serialized **as exact decimal strings**, not JS float arithmetic.

## Fail-closed privacy/read invariants

- Unknown project/video combination -> typed \`project_video_unavailable\` mapped to HTTP 404; IAM must first authorize the project. No global video enumeration.
- \`not_calculated\`, \`queued\`, \`running\`, \`blocked\`, \`cancelled\` or other noncomplete run -> \`score=null\`, no timeline or cohort numeric payload and explicit reason/quality status.
- A previous complete C7 that is currently expired/retracted/superseded/erasure-requested -> \`state=unavailable\`, specific denial code and no score, config/approval/peer/timeline numerics. The client independently enforces the same denial masking if a misbehaving response includes forbidden old numbers.
- A fully verified complete run -> exact source-policy-version and C7 evidence hash, original four Decimal contributions, original signed human decision and three optional project-owned cohort freeze records. Current permissions are independently reevaluated on **each** request, not cached.
- No testing/dev bearer token or IAM verifier is shipped in Studio. Hosting must supply secure HTTPS origin, real project IAM, same-origin static asset serving, request-rate limiting, session lifecycle/log redaction, and privileges denying direct historic \`calculated_metrics\` bypass. Direct viewing through the legacy \`app.py\` server is NOT wired: it requires an explicit deployment mount or separately approved host integration. Do not put access tokens in user-facing deep links or logs.
