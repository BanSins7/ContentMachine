No external rights-cleared human speaker or real music/SFX is bundled. **Do not claim a Russian or English ASR WER gold score from beep/noise or burned-in text.**
- Every generated file gets an observed SHA-256 + byte length in `manifest.json`; every source byte is rehashed before/after benchmarking; carousel evaluation must pin ordered SHA for all original slides. Source definitions and executable tool versions stay in the manifest. - Quality baseline: `tests/fixtures/group_a_benchmark_calibration_v1.json`. All 11 release thresholds deliberately `null`, with independent review marked false until actual licensed human gold is provided and separately validated. Any automatic "PASS" from two synthetic images would be fabricated.
- Harness code: `benchmark_metrics.py` (scene boundary matching with explicit tolerance, RU/EN Unicode WER/CER, OCR matched-line CER/recall, subtitle positive/negative/abstention/unknown and coverage, per-label audio event IoU micro precision/recall), `benchmark_runner.py` (source-SHA pinned measured FFprobe/FFmpeg decode/Tesseract, optional host-authenticated prediction scoring, slot-free hypothetical 10k/month planning), `benchmark_fixtures.py`, `scripts/benchmark_group_a.py`, `tests/test_group_a_benchmark.py`.

## 4. 10,000/month is a hypothetical scenario, not achieved throughput

Calculator `planning_estimate_10k` uses **30 days × 86,400 seconds/day × assumed worker slots × assumed effective utilization ÷ assumed measured full-pipeline seconds per asset**. With **no full pipeline timing**, the normal result is `status=unavailable_no_measured_full_pipeline`, `estimated_workers_required=null`, not a fabricated 10k KPI.

Pure illustration, **arbitrary assumptions** (not observed):

- If a full pipeline eventually measured 120 sec/asset with utilization 0.65, one ideal worker slot would theoretically process 14,040 assets/month.
- If the full pipeline instead required 600 sec/asset at the same utilization, one slot would theoretically process 2,808 assets/month, so **four** independent slots would be needed to target 10,000/month.
- These ignore external provider rate caps, source availability, model/GPU memory, review, network/B queue, distribution of video duration, maintenance and task rejection. **Neither scenario is validated.**
