# AI Avatar Studio · экспериментальная ветка (2 ноября 2026)

Ветка: `feature/ai-avatar-carousel-studio-20261102` (создана от `main`). Изменения не объединены с `main`.

## Что работает

- Отдельная минималистичная страница `http://127.0.0.1:8765/avatar-studio.html`, ссылка в «Инструменты».
- Загрузка или drag-and-drop **одного** PNG/JPEG/WebP до 10 МБ; локальный предварительный просмотр.
- Промпт на 20–15 000 символов, варианты High / XHigh / Max, портрет/квадрат/горизонталь.
- Настоящий запрос к OpenAI `POST /v1/images/edits` с `model=gpt-image-2.5-sunburst` и референсом `image[]` (без имитации результатов).
- Серверные jobs: создание → очередь → выполнение → успех/ошибка, без блокировки интерфейса; опрос статуса.
- История последних 30 запусков, сохранённый PNG, восстановление референса/промпта/параметров и скачивание.
- Обработка повреждённых файлов, неподдерживаемых форматов, отсутствия API-ключа, ошибок OpenAI 400/401/403/429/5xx, таймаута, потери сети, некорректного ответа и ошибок диска.
- **Нет автоматических повторных платных запросов.** При таймауте выполнение могло завершиться у провайдера, поэтому перед повтором проверьте биллинг/историю.
- Никакой генерации без явного нажатия кнопки.

## Первый запуск на Windows

1. Убедитесь, что рабочая копия чистая: `git status`. Затем:
   ```powershell
   cd C:\ContentMachine
   git fetch origin
   git switch feature/ai-avatar-carousel-studio-20261102
   ```
2. Для реального OpenAI API нужен **отдельный** API-биллинг (подписка ChatGPT не заменяет его). Перед запуском задайте переменную окружения (не добавляйте ключ в Git):
   ```powershell
   $env:OPENAI_API_KEY = 'ВАШ_OPENAI_API_KEY'
   .\START_CONTENTMACHINE.bat
   ```
   Альтернативно один раз сохраните ключ в **локальном игнорируемом Git файле** `worker/openai_api_key.txt` (файл не нужно отправлять в чаты и GitHub).
3. Откройте `http://127.0.0.1:8765/avatar-studio.html`, загрузите референс, вставьте промпт, выберите параметры, нажмите «Сгенерировать фотографию».
4. Не используйте `RUN_AUTO.bat` для проверки отдельной ветки: автоматический updater установки ориентируется на `main`.

## Данные и интерфейс

Локальные файлы: Windows `%LOCALAPPDATA%ContentMachineDataavatar-studio<job-id>`, Linux/macOS `~/.contentmachine/avatar-studio/<job-id>/`. Переопределение: `CM_AVATAR_STUDIO_DIR`.

Содержимое каталога: `job.json` (включает промпт/статус/usage), `reference.{png,jpg,webp}`, `result.png` при успехе. Все файлы выдаются через ограниченный localhost HTTP endpoint, где имена jobs строго валидируются.

API:
- `GET /api/avatar-studio/status` — модель и состояние настройки (никогда не возвращает ключ).
- `GET /api/avatar-studio/history` — список последних jobs.
- `GET /api/avatar-studio/jobs/{id}` — состояние.
- `GET /api/avatar-studio/files/{id}/reference|result` — локальное изображение.
- `POST /api/avatar-studio/generate` — JSON, поля: `reference` (Data URL), `prompt`, `quality`, `size`, требуется штатный локальный заголовок `X-ContentMachine: 1`.

## Тестирование

Без платежей:
```powershell
python -m unittest discover -s tests -p "test_avatar_studio.py" -v
python -m py_compile app.py avatar_studio.py
node --check site/avatar-studio.js
```

Сетевая генерация с реальным OpenAI API **не тестировалась** при подготовке ветки; нужна проверка на пользовательской машине с доступом и оплачиваемым API. Если браузер не открывает страницу, проверьте, что запущен именно этот checkout. Все операции замены reference/output безопасно ограничены рабочей папкой.
