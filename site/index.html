03 · Query Validation

Только реальная offline multilingual embedding модель, без тестового fallback.

Семантические пороги
Эксперимент A/B · Jina Query Expansion (реальные API)

Сравнение на одних и тех же завершённых запросах SP4. A — исходный текст, B — LLM-расширение в стиле исследования Jina; обе ветки используют hosted jina-embeddings-v3 (retrieval.query / retrieval.passage). Никакой локальной модели. Запуск вызывает платные внешние API OpenRouter и Jina; не записывает QV, не отправляет запросы в Collector. Показатели similarity и drift не являются измерениями точности найденных видео.

Настройки сервера: CM_SP_JINA_AB_ENABLED=1, CM_SP_JINA_AB_LLM_MODEL, OPENROUTER_API_KEY, JINA_API_KEY. Только локальный владелец. SP4-промпт в основном pipeline не изменяется.
