# ContentMachine — Instagram Downloader

Первый локальный модуль будущей ContentMachine: аккуратная веб-панель для скачивания Instagram Reels и получения субтитров. TikTok и YouTube Shorts запланированы на следующие итерации.

![Статус](https://img.shields.io/badge/status-local%20MVP-8b7bf0)

## Быстрый запуск на Windows

1. Установите **Python 3.10+**.
2. Скачайте репозиторий (GitHub → Code → Download ZIP) и распакуйте.
3. Закройте предыдущий `Content Zavod` / `local_worker.py`, если он запущен (они используют один порт `8765`).
4. Запустите **`START_CONTENTMACHINE.bat`** двойным щелчком. Скрипт установит зависимости, если их нет.
5. Откроется **http://127.0.0.1:8765** — это сайт на вашем компьютере, без отдельного хостинга.

**macOS / Linux:** `bash START_MAC_LINUX.sh` (при необходимости используйте виртуальное окружение).

## Как пользоваться

- Введите одну или несколько ссылок `https://www.instagram.com/reel/SHORTCODE/` (до 75 за запуск).
- Выберите папку (например, `dr.velskaya`) и способ транскрибации: **OpenRouter** или бесплатный **Whisper**.
- Нажмите «Скачать видео». Состояния заданий отображаются ниже, без перезагрузки страницы.
- Видео и файлы доступны в библиотеке сайта и в `~/Downloads/InstagramArchive/<аккаунт>/`.
- Режим «Найти Reels по профилю» пробует извлечь список публикаций через `yt-dlp`; Instagram может ограничить или запретить такие запросы. При ошибке вставьте ссылки на видео вручную.

Для каждого ролика создаются `SHORTCODE.mp4`, `SHORTCODE.srt`, `SHORTCODE.txt`, `SHORTCODE.json`, а в корне `InstagramArchive/` обновляется `index.csv`.

## OpenRouter

Ключ можно ввести через **Настройки** сайта или сохранить в файле `worker/openrouter_key.txt`. Значение ключа **не возвращается** в браузер и не выводится в журнал. Сайт сохраняет настройки локально. Локальный лимит расходов около $1 не заменяет настоящий лимит API-ключа в OpenRouter. При ошибке OpenRouter обработчик пробует локальный Whisper.

**Примечание:** репозиторий содержит личную настройку OpenRouter, добавленную по запросу владельца. Держите репозиторий приватным; при публикации репозитория в открытый доступ замените ключ.

## Технически

- Сервер: Python, `ThreadingHTTPServer`, без облака и отдельной базы.
- Загрузка видео: проверенный адаптер `yt-dlp` с подтверждением shortcode; при несовпадении скачивание прекращается.
- Проверка MP4 и звука: `PyAV`.
- Субтитры: `microsoft/mai-transcribe-2` в OpenRouter, резервный `faster-whisper` на компьютере.
- Библиотека: существующая директория `~/Downloads/InstagramArchive`.
- Сайт: чистые HTML, CSS и JavaScript, без npm и этапа сборки.

API ограничен `127.0.0.1:8765`. Не публикуйте локальный порт в интернет и не выкладывайте папку архива видео на публичный хостинг.
