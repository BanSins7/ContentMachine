# ContentMachine · Instagram Downloader

Минималистичный локальный веб-интерфейс для Instagram Downloader. В боковой панели только **Instagram Downloader**.

## Запуск

1. Установите Python 3.10+.
2. Скачайте ZIP репозитория и распакуйте.
3. Если установлен предыдущий Content Zavod, остановите его локальный сервер на порту 8765.
4. Windows: запустите `START_CONTENTMACHINE.bat`. macOS/Linux: `bash START_MAC_LINUX.sh`.
5. Откройте `http://127.0.0.1:8765`.

## Как пользоваться

1. Вставьте ссылку на Reels (`https://www.instagram.com/reel/SHORTCODE/`) **или** на профиль (`https://www.instagram.com/USERNAME/`).
2. Нажмите **Найти**. Для отдельного ролика ссылка проверяется сразу. Для профиля сервер пытается собрать список публикаций через `yt-dlp`. Instagram иногда блокирует автоматический сбор профилей; при этом будет показана понятная ошибка.
3. Когда появится количество найденных видео, нажмите **Скачать**.
4. Следите за прогрессом: во время загрузки отображается фактический процент передачи данных, а при распознавании — индикатор без выдуманной оценки времени.

Сохраняется по одинаковым именам: `SHORTCODE.mp4`, `SHORTCODE.srt`, `SHORTCODE.txt`, `SHORTCODE.json`, таблица `index.csv`.
Файлы находятся в `~/Downloads/InstagramArchive/<username или instagram>/`.

Вверху всего две метрики: число сохранённых видео и сумма расходов на OpenRouter по локальному журналу запросов. Это **не баланс OpenRouter** и не подтверждение полного биллинга провайдера.

## OpenRouter

Сервер берёт ключ из локального `worker/openrouter_key.txt` (или переменной окружения, если поддерживается локальным обработчиком). Ключ не нужен для работы локального Whisper, но без него будет выбран бесплатный режим. **Ключ не сохраняется в GitHub**: файл исключён через `.gitignore`.

## Технологии

- Python HTTP-сервер на `127.0.0.1:8765`.
- `yt-dlp` для проверки и скачивания конкретного Instagram Reels.
- OpenRouter MAI-Transcribe 2 или faster-whisper для субтитров.
- Статический HTML/CSS/JavaScript, никаких npm-зависимостей.

Проверки: `python -m unittest discover -s tests -v` и `node --check site/app.js`.

Следующие инструменты ContentMachine — TikTok и YouTube Shorts — будем добавлять позднее, не загромождая текущий экран.
